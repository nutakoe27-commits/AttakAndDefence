# Attack & Defence

Браузерная PvP-стратегия (tower defense + атака юнитами) на процедурно генерируемых картах.
Игра идёт **раундами**: 20 секунд скрытого планирования (стройка + очередь армии, противника не видно),
затем **бой** — обе армии выходят одновременно и сражаются до последнего юнита. Побеждает тот,
кто уничтожит вражескую базу. Расчётная длительность матча при равных силах — **10–15 минут**.

## Возможности

- ⚔ **PvP-матчмейкинг** — очередь на двоих; если соперник не найден за 20 секунд, подставляется **бот средней сложности** (таймаут настраивается в админке).
- 👥 **Игра с другом** — приватная комната: хост получает 4-значный код и ссылку-приглашение (`/?room=КОД`); друг вводит код или просто открывает ссылку. Бот в комнаты не вмешивается, комната живёт 15 минут.
- 🗺 **Процедурные карты «коридор в горах»** 46×30 — каждый матч генерируется новый обязательно извилистый коридор между базами. Юниты ходят только по коридору; башни и экономика строятся **на горах** и простреливают путь сверху (классический TD). Карта симметрична (поворот на 180°), связность гарантирована.
- 🎲 **Раундовый режим**: фаза планирования 20 сек (действия противника скрыты — его новые постройки и армия раскрываются только с выходом войск) → фаза боя до гибели всех юнитов (с «усталостью» против вечных боёв). Очередь юнитов можно отменять с возвратом золота.
- 💰 **Экономика раундами с разгоном**: золото выдаётся разом в начале раунда, базовая выплата растёт с каждым раундом, шахты добавляют, банки умножают. К концу матча — застроенные горы и волны под лимит армии (90 юнитов).
- 🪖 **6 типов юнитов**: скаут, солдат, лучница, танк, разрушитель (осадный), целитель. Выходят разом в начале боя и сражаются сами; лес в коридоре замедляет.
- 🏰 **5 построек**: шахта и банк (экономика), стрелковая башня, пушка (сплэш), криобашня (замедление). Лучшие места для башен — изгибы коридора. Постройки неуязвимы для юнитов: юниты сражаются друг с другом и бьют только вражескую базу.
- 🧠 **Умный, но человечный бот**: анализирует карту (покрытие коридора из каждой горной клетки), ставит башни в изгибах и кластерами, собирает разведку между раундами и копит «тяжёлый кулак», если его волны дважды разбились об оборону. При этом ошибается и делает паузы — победить можно.
- ⏱ **Sudden death** после 10:30 — базы начинают разрушаться сами, затяжные матчи гарантированно заканчиваются к 15-й минуте.
- 🎓 **Обучение** при первом запуске + справка «Как играть».
- 📱 **Мобильная версия** (ландшафт): пан пальцем, пинч-зум, стройка «тап → ✓ Построить», long-press для описаний, компактный HUD, кнопка полноэкранного режима, в портрете — просьба повернуть телефон.
- 🛡 **Админ-панель** (`/admin`): дашборд, live-матчи с возможностью остановки, история, **аналитика баланса** (pick/win rate юнитов и построек, баланс сторон, экономика — из БД), редактор баланса (правки применяются к новым матчам без рестарта) и настройки бота/матчмейкинга.
- 📊 **Статистика в БД** (`node:sqlite`, без зависимостей): по каждому матчу пишутся юниты/постройки/экономика по типам для регулирования баланса.
- 🌐 **Локализация RU/EN**: автоопределение языка (SDK Яндекса → браузер), ручной переключатель 🌐, переведено всё — интерфейс, юниты, обучение, ошибки сервера и даже имена ботов.
- 🏆 **Лидерборд**: рейтинг (победы над людьми +25, над ботом +10), топ-50 и своё место — в меню; на Яндексе рейтинг дублируется в нативный лидерборд платформы.
- 📈 **Прогрессивное усиление войск**: с каждым раундом юниты выходят с большим HP и уроном (+10%/+6% за раунд) — поздние волны пробивают плотную оборону, и дешёвые юниты остаются полезными до конца матча.
- 🎮 **Готовность к Яндекс Играм**: интеграция SDK (реклама, облачные сохранения, пауза, `ready()`), билд статического бандла (`npm run build:yandex`). Подробно — [YANDEX.md](YANDEX.md).
- 🔌 **Реконнект**: при обрыве связи игрок возвращается в свой матч (25 секунд до технического поражения).
- Сервер **авторитарен**: вся симуляция на сервере (8 тиков/с), клиент только рендерит и шлёт команды.

## Быстрый старт

```bash
npm install
npm start          # сервер на http://localhost:3000
```

Переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт HTTP/WS сервера |
| `HOST` | `0.0.0.0` | Интерфейс |
| `ADMIN_PASSWORD` | `admin` ⚠ | Пароль админки — **обязательно смените на проде** |
| `PUBLIC_ORIGIN` | — | Публичный адрес (заглушка под будущий домен, см. DEPLOY.md) |
| `STATS_DB` | `server/data/stats.db` | Путь к файлу БД статистики (нужен Node ≥ 22.5) |

## Тесты

```bash
npm test            # смоук: генерация карт, механики, бот-против-бота (баланс длительности)
node test/e2e.js    # e2e: статика, админ-API, PvP через WebSocket, бот-фоллбек, реконнект
```

## Структура

```
server/
  index.js          — HTTP (статика + admin API) и WebSocket
  match.js          — матчмейкинг, раннер матчей, реконнект
  admin.js          — API админки (логин, метрики, баланс)
  balance.js        — конфиг баланса (дефолт + правки из админки)
  config/balance.json — весь игровой баланс (юниты, постройки, экономика, бот)
  game/
    mapgen.js       — процедурная генерация карт
    sim.js          — симуляция боя (пути, бой, экономика, sudden death)
    bot.js          — ИИ противника
public/
  index.html, css/, js/   — игровой клиент (Canvas 2D)
  admin/                  — админ-панель
test/               — смоук и e2e тесты
DEPLOY.md           — инструкция по развёртыванию на своём сервере
```
